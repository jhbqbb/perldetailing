# perl.

Website für perl. – mobile Autoaufbereitung in München.

Statische Seite (`index.html`), keine Abhängigkeiten.

## Lokal starten

```bash
python3 -m http.server 3000
```

→ http://localhost:3000

## Online (GitHub Pages)

Settings → Pages → Branch `main` → `/ (root)` → Save.
